# cascade-dropdown (plugin `forms`, frontend)

Entry UI de configuração de um campo `RELATIONSHIP` em dois níveis dependentes
(pai → filtra filho). Slot `table.field.relationship.config`. `index.tsx` com
`export default`, consumindo `/plugins/cascade-dropdown/*` do backend.

Ver [../../CLAUDE.md](../../CLAUDE.md) (`frontend/extensions/forms/`) e a
contraparte em `backend/extensions/forms/plugins/cascade-dropdown/`.

# copy-record-link (plugin `core`, frontend)

Entry UI do plugin que copia o link direto do registro
(`/tables/<slug>/row/<rowId>`) para a área de transferência. Slot
`table.row.actions` (item no dropdown de ações da linha). `index.tsx` com
`export default`.

Pacote `core` é auto-ativado no boot. Ver [../../CLAUDE.md](../../CLAUDE.md)
(`frontend/extensions/core/`) e `backend/extensions/core/plugins/`.

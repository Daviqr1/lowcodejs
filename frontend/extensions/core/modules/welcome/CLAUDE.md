# welcome (módulo `core`, frontend)

Entry UI do módulo de boas-vindas (URL default `/e/core/welcome`). `index.tsx`
com `export default` — montado pela rota dinâmica
`routes/_private/e/$package/$id/`. Pode ser anexado a um menu custom.

Pacote `core` é auto-ativado no boot. Ver [../../CLAUDE.md](../../CLAUDE.md)
(`frontend/extensions/core/`) e `backend/extensions/core/modules/welcome/`.

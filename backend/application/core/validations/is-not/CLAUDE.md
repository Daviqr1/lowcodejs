# is-not — Regra de validação de campo

`export default new IsNotRule()` (`FieldValidationRule`, `requiresConfig`).
Rejeita o valor quando ele está na lista da config `{ values: string[] }`. Regra
pura/síncrona; ignora valor vazio.

Contrato, registry e visão geral das 15 regras em [../CLAUDE.md](../CLAUDE.md).
